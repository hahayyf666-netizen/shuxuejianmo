# Q1 全量特征生产合同 v1.0

编制日期：2026-09-24。适用范围：附件1中100个唯一视频片段；仅完成Q1第一版特征生产与交付，当前仍处于2.1.7 REVIEW GATE的第一版闭合任务，不进入2.2。

## 1. 依据和输入

- 官方样本文本逐字取附件1 `label-100.xlsx` 的 `text` 列；不改写，不以ASR替换。
- 声学数据取对应原MP4音轨；视觉数据取对应原MP4画面。原始MP4和官方标签表由SHA-256固定身份。
- 采用现行 shared presentation timeline。音频窗与视频帧都保存绝对呈现时间；不以 `frame_index / fps` 重建时间，不忽略或重写MP4 edit list。
- 采用用户提供的官方答疑截图作为业务处理口径：100条原样保留；静音仍提取真实声学特征；无脸只影响面部特征mask；官方文本与讲话错配时保留A/V与官方文本但不伪造词时间。三张原始截图及其SHA-256索引保存于`metadata/official_answer_evidence/`和`metadata/official_answer_evidence.json`。
- stable-ts 2.19.1既有逐词诊断仅在原MP4哈希、官方文本哈希、诊断trace哈希均匹配，且审计已有内容证据确认文本与讲话基本一致时，才用于词级派生。此次不重跑transcribe或forced alignment。

## 2. 路由合同

先确认样本键、官方文本、来源文件、共享A/V时间轴。任何身份或共同时间轴无法确定的情况记为 `EXTRACTION_OR_TIMELINE_ANOMALY` 并停止受影响生产；不得自行改素材或时间语义。

| 情形 | `alignment_mode` | 生产粒度与处理 |
|---|---|---|
| 有既有人内容匹配结论，且哈希核验的官方词trace可映射 | `TRI_MODAL_WORD_VALID` | 保存全部官方词；可用词按冻结center规则聚合audio/vision；零时长或无观测词保留并置逐词mask，不修边界 |
| 审计证据确认数字静音/无人声，A/V时间轴可靠 | `TRI_MODAL_WITH_AUDIO_CONTENT_INVALID` | 保留真实openSMILE值；`audio_speech_valid=0`；记录clip级文本与A/V，不把静音均分到官方词 |
| 审计已有人工确认文本与实际讲话不对应 | `AV_VALID_TEXT_UNALIGNED` | 官方文本与实际A/V都保留；text只在clip级关联；词时间不可用 |
| 现有内容证据不足以支持词级映射 | `UNCERTAIN_REVIEW` | 作为完成的保守clip-only生产分支：保留text词向量和原生A/V序列，所有官方词时间置NaN、时间mask置0；不把ASR相似度、概率或区间结构写成内容确认 |
| 来源、解码或A/V共同时间轴异常 | `EXTRACTION_OR_TIMELINE_ANOMALY` | 保存故障证据，不能计为完整特征交付 |

`UNCERTAIN_REVIEW`表示内容对应证据级别不足以支持词映射，不代表向参赛者分派逐条人工听辨任务，也不妨碍该样本以clip-only粒度交付。此状态与机器候选表中“human review pending”字段语义分开，最终manifest不设置待用户复核任务。

`SAMPLE_FAIL`、`HARD_STOP`、`PAUSED_RESOURCE`、`NOT_RUN_AFTER_HARD_STOP`是执行状态，不是数据内容类别。失败行保留已核实的样本及模态存在性；未实际解码/提取的观测有效性字段必须为空或unknown。失败样本不计入成功特征文件，必须恢复并通过验收后才可报告100条闭合。媒体/文本按样本边界隔离；超时上限固定，最多进行2次相同参数尝试；可用内存低于1 GiB时在下一个样本前暂停，禁止把超时、资源暂停或解码异常改写为文本错配。

## 3. 特征定义

- 文本：RoBERTa-base最后隐层；按官方原文字符跨度，对每个官方非空白词所对应subword向量取算术均值，768维。保留token偏移和word-subword索引。
- 音频原生序列：PyAV从原MP4解码音轨并重采样为16 kHz单声道；openSMILE eGeMAPSv02 LowLevelDescriptors，25维，每个LLD窗口保存绝对start/end/center。静音也照常计算并保留真实返回值。
- 视频原生序列：PyAV解码帧presentation PTS；MediaPipe FaceLandmarker VIDEO模式、`num_faces=1`、blendshapes输出；每个视频帧保存PTS、支持区间、52维向量和逐帧face mask。每条样本创建独立landmarker实例。
- 词级派生：仅在合同允许词级映射的样本产生。对半开词区间 `[start,end)`，选取 `start <= feature_center < end` 的LLD窗或视频帧；计算逐维均值和总体标准差（`ddof=0`），维度分别为50与104。无有效观测时该词值置0并由mask表达。
- 变长分模态：`text_sequence_length`、`audio_observation_length`、`video_observation_length`分开记录。不padding、不删官方词、不把原生A/V强行变成词数行。clip-only样本仍有完整text词向量和原生audio/video时序；其逐词A/V派生数组仅为无效占位并由mask标明。

文本词单元使用固定规则：先按原文Unicode空白分块；含至少一个Unicode字母或数字的块作为词单元，纯标点块不单独编码，而并入相邻词的字符跨度（行首标点并入首词）。原始`official_text`始终逐字保留，不删除或改写任何字符。按空白切分的块数为1932；其中6块是独立引号、破折号或省略号等纯标点，合并入相邻词后，100条文本特征序列共1926个词单元。此规则适用于字符跨度、RoBERTa子词映射与`text_sequence_length`，不能将二者计数口径混写。

## 4. 状态字段

- `text_present/audio_present/video_present`表示对应模态原始输入存在；全部来自附件1标签与MP4轨道/解码证据。
- `audio_observation_valid=1`表示有实际、有限的声学LLD观测；不表示存在人声。
- `audio_speech_valid`采用三态整数：`1`已有强语音证据，`0`已确认无人声/数字静音，`-1`现有证据不足。静音的2条已由原始音频逐采样为零的审计证据确认；非零音频不自动等于有效人声。
- `vision_feature_valid/face_feature_valid`表示此MediaPipe特征提取器是否至少在一帧产出有效52维blendshape；无有效检测时为0，但`video_present`仍为1，帧位置和mask仍保留。
- `text_audio_correspondence`只填写审计已有明确的人内容证据：`confirmed_match`、`confirmed_mismatch`、`no_speech`；其余为`not_asserted`。不把机器screen当作人工事实。
- `text_av_time_mapping_status`为`word_valid`、`word_partial`、`clip_only`或`unavailable`。`clip_only`不含官方词时间声明。
- 新schema字段不修改A0 NPZ中旧 `audio_valid`、`vision_valid`、`alignment_valid` 的含义或字节内容。

## 5. 交付约束

- 每条样本一个`allow_pickle=False`可读的压缩NPZ，manifest恰好100行并可按哈希复核。
- 不向模型特征写入情绪目标标签；官方文本保留，标签列不进入NPZ。
- 程序、依赖锁定、环境、配置、输入证据、逐样本日志、读取/验证示例、报告与附件大小审计随交付保存。
- 全量manifest与`results_100.csv`字段以`02_字段与文件规范.md`为准；验证器会直接重算当前源MP4 SHA、逐词字符跨度、center筛选CSR索引与均值/标准差。
- 第一版闭合只表示原题Q1产物和复现入口交付齐全、结构和来源审计通过；不表示所有官方词都有人工确认的毫秒级边界，也不代表进入2.2或Q1冻结。
