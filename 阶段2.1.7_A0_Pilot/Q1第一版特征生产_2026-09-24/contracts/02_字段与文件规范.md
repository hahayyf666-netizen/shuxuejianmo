## NPZ字段

所有NPZ均须以`numpy.load(path, allow_pickle=False)`读取。字符串存为NumPy Unicode数组，缺失词时间只允许以NaN和`word_time_valid=0`表达。有效数值特征必须有限。

| 字段 | dtype / 形状 | 含义 |
|---|---|---|
| `schema_version` | string scalar | `q1-feature-v1.0` |
| `sample_key`, `video_id`, `clip_id` | string scalar | 官方样本唯一键 |
| `official_text` | string scalar | `label-100.xlsx`原文 |
| `source_video_sha256`, `source_label_xlsx_sha256`, `alignment_trace_sha256` | string scalar | 输入与复用对齐证据身份 |
| `alignment_mode`, `alignment_granularity`, `text_audio_correspondence`, `text_av_time_mapping_status` | string scalar | 路由与声明的时间粒度 |
| `text_present`, `text_content_valid`, `audio_present`, `audio_observation_valid`, `audio_speech_valid`, `video_present`, `audio_visual_time_valid`, `vision_feature_valid`, `face_feature_valid` | uint8/int8 scalar | 分离存在性、观测、内容和时间状态；`audio_speech_valid=-1`为unknown |
| `words` | `[L]` Unicode | 官方原文按固定规则得到的词序列，保留标点 |
| `word_char_start`, `word_char_end` | int32 `[L]` | 左闭右开官方字符跨度 |
| `word_start_sec`, `word_end_sec` | float64 `[L]` | 可信词区间；不可用位置为NaN |
| `word_time_valid`, `text_word_valid`, `word_audio_valid`, `word_vision_valid` | uint8 `[L]` | 逐词有效性mask，不改变词序 |
| `text_word_feat` | float32 `[L,768]` | 官方text的RoBERTa词向量 |
| `word_audio_feat` | float32 `[L,50]` | 有可信映射时按center聚合的25维均值+25维总体标准差 |
| `word_vision_feat` | float32 `[L,104]` | 有可信映射时按center聚合的52维均值+52维总体标准差 |
| `raw_audio_lld_values` | float32 `[K_a,25]` | 原生音频LLD窗；静音保留提取器真实值 |
| `raw_audio_lld_start_sec/end_sec/center_sec` | float64 `[K_a]` | LLD窗绝对presentation时间 |
| `raw_audio_lld_valid`, `raw_audio_lld_feature_names` | uint8 `[K_a]`, string `[25]` | 有限值mask与特征顺序 |
| `raw_video_blendshape_values` | float32 `[K_v,52]` | 逐帧面部blendshape；无脸帧用零占位，需结合mask |
| `raw_video_pts_sec`, `raw_video_support_start_sec`, `raw_video_support_end_sec` | float64 `[K_v]` | 解码PTS及该帧支持区间 |
| `raw_video_face_feature_valid` | uint8 `[K_v]` | 每帧MediaPipe有效输出mask |
| `raw_video_blendshape_names` | string `[52]` | 固定类别顺序 |
| `audio_word_feature_indptr/indices`, `vision_word_feature_indptr/indices` | int32 | 每词选中的原生观测索引，CSR式表达 |
| `roberta_token_ids`, `roberta_token_offsets`, `roberta_token_word_index`, `roberta_word_token_indptr/indices` | int32数组 | 可逆检查subword到官方字符跨度的映射 |
| `audio_presentation_coverage_sec`, `video_presentation_coverage_sec`, `av_common_coverage_sec` | float64 `[2]` | 各模态及共同覆盖范围 |
| `shared_t0_sec`, `original_effective_duration_sec` | float64 scalar | 共同原点及有效覆盖长度 |
| `audio_observation_length`, `video_observation_length`, `text_sequence_length` | int32 scalar | 各模态真实位置数，互不替代 |
| `alignment_zero_duration_word_count`, `alignment_mapping_fail_count` | int32 scalar | 复用的对齐诊断计数，不解释为内容真值 |
| `diagnostic_alignment_probability_summary_json` | string scalar | 原诊断概率摘要，仅供复核 |
| `config_sha256`, `roberta_model_sha256`, `roberta_asset_identity_sha256`, `mediapipe_model_sha256`, `opensmile_config_sha256` | string scalar | 版本化运行配置及实际模型/配置资产身份 |

## manifest.csv 与 results_100.csv 列

写入器及独立验证器共同要求以下列，失败样本也保留一行：

| 列组 | 字段 |
|---|---|
| 样本与来源 | `sample_key`, `video_id`, `clip_id`, `official_text`, `official_text_sha256`, `source_relpath`, `source_mp4_sha256`, `source_label_xlsx_sha256`, `stage1_duration_proxy_sec`, `alignment_trace_sha256` |
| 产物身份 | `status`, `output_file`, `output_sha256`, `output_bytes`, `config_sha256`, `roberta_asset_identity_sha256`, `mediapipe_model_sha256`, `opensmile_config_sha256` |
| 模态与长度 | `modalities`, `text_sequence_length`, `audio_observation_length`, `video_observation_length`, `feature_dims_json`, `original_effective_duration_sec` |
| 对应关系 | `alignment_mode`, `alignment_granularity`, `text_audio_correspondence`, `text_av_time_mapping_status` |
| 存在/有效状态 | `text_present`, `text_content_valid`, `audio_present`, `audio_observation_valid`, `audio_speech_valid`, `video_present`, `audio_visual_time_valid`, `vision_feature_valid`, `face_feature_valid` |
| 计数与时间覆盖 | `official_word_count`, `valid_word_time_count`, `text_word_valid_count`, `audio_word_valid_count`, `vision_word_valid_count`, `audio_coverage_start_sec`, `audio_coverage_end_sec`, `video_coverage_start_sec`, `video_coverage_end_sec`, `av_common_coverage_start_sec`, `av_common_coverage_end_sec` |
| 执行信息 | `process_rss_bytes`, `runtime_sec`, `error` |

`modalities`只表示来源模态存在；`audio_observation_valid`表示已实际得到有限声学特征，不能因原始MP4中有音轨就预填为1。执行失败的行保留已核实的源模态存在性，尚未观测的字段留空/unknown，`status`记录`SAMPLE_FAIL`、`HARD_STOP`、`PAUSED_RESOURCE`等状态；此类行不算成功交付，也不能由空NPZ补齐。只有`status=PASS`且NPZ通过独立验证，才计入成功特征文件。

全量生产时`manifest.csv`与`results_100.csv`恰好各100行，sample_key集合与`input_manifest.csv`完全相同且各出现一次；代表分支验证目录可按9条选择范围生成同schema表。两表逐行同步sample_key、状态和输出SHA；验收器逐条重算源MP4 SHA、官方文本、词跨度、center索引/CSR与均值/标准差。

## 兼容读取

最小读取方式：

```python
import numpy as np
with np.load(path, allow_pickle=False) as z:
    mode = str(z["alignment_mode"].item())
    text = z["text_word_feat"]
    audio_native = z["raw_audio_lld_values"]
    video_native = z["raw_video_blendshape_values"]
    audio_times = z["raw_audio_lld_center_sec"]
    video_times = z["raw_video_pts_sec"]
    word_audio_mask = z["word_audio_valid"].astype(bool)
```

不得仅按数组行号配对不同模态；词级派生要读取逐词mask，原生A/V查询要使用各自的绝对presentation时间。
