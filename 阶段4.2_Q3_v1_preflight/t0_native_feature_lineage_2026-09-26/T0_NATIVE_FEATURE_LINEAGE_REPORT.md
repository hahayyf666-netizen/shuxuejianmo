# Q3 T0 原生特征来源行重建审计

日期：2026-09-26。范围：预先冻结的附件4样本 `02, 03, 07, 13, 16`。本轮未读取情感标签、模型预测或解释分数；未更改 B0/B1、Shapley、conditional IG、valid120，也未运行附件4正式推理。

## 1. 问题与预先冻结的判据

要验证的链是 `官方 aligned[i] → 官方 unaligned[j] → 带时间戳的候选原生特征[r]`。前一段由 C-2 已审计。本轮只验证后一段，不能仅凭同维度、序号比例、词时间、CKA 或接近的时长推断。五条样本与阈值在读取候选特征值前写入 `results/t0_frozen_contract.json`。

候选来源为固定提交 `ee52115996266573d2e3c2a3e04fd19e52af74c8` 的公开 CMU-MOSEI CSD 镜像：74 维 COVAREP、35 维 FACET 4.2 和带时间词序列。它不是比赛附件的官方生成日志，是否同源只由本轮逐行数值匹配决定。远程文件用 HTTP Range 只读访问，检查 HDF5 文件头、总长度、每次 Content-Range 和 ETag；保存镜像版本与 ETag。词序列只用于找到候选原视频组，不能单独证明时间映射。

严格匹配要求：维度相同、每行最大绝对误差 ≤`1e-4`、相对 L2 误差 ≤`1e-6`、次近邻的最大绝对误差 ≥`1e-3`，全部官方有效行匹配、来源行严格递增、来源时间区间为正，且错误视频负对照不得匹配。事实上本轮所有匹配行的逐维最大绝对误差都为 **0**。候选 CSD 中非有限行在近邻搜索前排除，不改变官方行。

## 3. 解释边界与 Gate

**SOURCE_ROW_GATE = PASS_FROZEN_FIVE。** 对这五条样本，官方未对齐特征行与候选公开 CSD 行存在可复核的逐维完全相等对应；因此可给出**原始长视频 CSD 时间坐标**。这比 `text[i] → forced alignment → 猜 audio/vision[i]` 多出一段真正被数值验证的桥。它不等同于拿到了比赛附件生成者的原始日志，也没有证明镜像覆盖全部20条或附件2的全部样本。

**ATTACHMENT4_LOCAL_TIME_GATE = BLOCKED_PENDING_CLIP_ORIGIN_VALIDATION。** CSD 的时间原点是来源长视频，附件4 MP4 的 presentation PTS 从零开始。两者的裁剪起点或 edit-list 映射尚无独立证据。虽然匹配的来源行时间跨度与剪辑时长相容，不能由此精确减去一个猜测 offset，直接报附件4的“第几秒”或解码本地“关键帧”。词序列的来源匹配也不能填补这一缺口：例如样本02官方文本的标准化词序列只在候选字幕中命中 6/15，不能当作可靠逐词时间锚。

**Q3 正式解释合同保持不变：音频/视觉仍为 `index_only`。** 这轮尚不扩展20条、不改解释协议、不开始新的训练或正式推理。只有独立核验长视频坐标到附件4 MP4 presentation PTS 的片段身份与起点后，才可考虑将通过样本升级为“可回看的重建时间”；届时仍须注明这是经重建验证的媒体定位，而非官方 extractor 原始采样窗口。对 `13/16` 还须保留单视觉行的低时间分辨率限制。
